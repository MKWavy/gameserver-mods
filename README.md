# Game Server Mod Sets

Fallback mirror of the mod sets for a private Terraria and
Vintage Story server. Published so players can install
manually if in-game auto-download fails.

⚠️ Both games download mods automatically when you join.
Try that first — this is a fallback.

The running server is always the source of truth. If a
download here doesn't match, this repo is out of date.

- `terraria-modlist.txt` — tModLoader 2026.05.3.0
- `vintagestory-modlist.txt` — Vintage Story 1.22.4

Full archives are attached to each Release, not committed.
